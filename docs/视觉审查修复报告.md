## P0 — 三项全部修复

### 1. 博客 ≤600px 无导航 → 已有汉堡菜单,断点提到 880px

`app.vue` 补上 `#navToggle` 按钮与 `menuOpen` 状态,`nav-links` 接 `:class="{ open: menuOpen }"`,点菜单项后路由变化自动收起。按钮复用已在 FA 子集内的 `fa-bars`,不引入新图标(子集只有 12 个字形),展开时靠 `rotate(90deg)` 做状态反馈。

折叠断点从 600px 提到 **880px**。原断点下换行区间实测在 601–870px(820px 时顶栏 101px,880px 起稳定 59px),折叠掉整段后:

| 视口 | 顶栏高度 | 导航 |
|---|---|---|
| 780 / 820 / 880px | 59px | 汉堡抽屉 |
| 920 / 960 / 1000 / 1440px | 59px | 展开,无按钮 |

实测开关行为(390 / 601 / 760px 三档均 OK):关闭 h=1 → 打开 h=367、`aria-expanded=true` → 再点收回 h=1;点菜单项跳转 `/posts` 后抽屉自动收起。

抽屉底色从单层玻璃(0.65)改为叠两层(合成 ~0.88 不透明),否则下面的卡片内容会透上来。

### 2. 博客 Font Awesome 竞态 → 已根治

`nuxt.config.ts` 的 bodyClose 脚本改为先判 `link.sheet` 是否已就绪,是则立即切 `media='all'`,否则挂 `load`/`error` 监听。

### 3. 状态站 5 个页面缺 reset → 移动端横向溢出清零

`login / admin / view-logs / api-management / player-history-chart` 五个页面补上与 `index.html` 一致的 `*{margin:0;padding:0;box-sizing:border-box}`。

## P1 — 全部修复

### 4. 博客浅色主题代码块

`style.css:492` 的 `.hljs{background:transparent}` 剥掉了 atom-one-dark 的深底,token 配色却留着。新增 token `--code-surface: #0d1117`,`<pre>` 在两种主题下都用它。绿色 token 从 1.95:1 变 9.4:1。

同一批连带修掉的:复制按钮改为深底浅字(3.88:1 → 通过)、语言标签固定浅色(2.73:1 → 通过)、`hljs-comment` 单独提亮(3.13:1 → 6.17:1)。

### 5. 正文链接与内联 code

这两项是长文章页 416 处不达标的大头(占 300 处):

- `.article-content a`:`--color-accent` → `--heading-accent`,2.99:1 → 5.97:1
- 行内 `<code>`:同上,**按父元素逐个点名**(`p/li/td/th/h1-h4/blockquote code`)而不是写 `.article-content code`——后者特指度高于 `.hljs-string`,会把 `<pre>` 里的语法高亮一起盖掉。这一点是我中途引入的回归,已修正。

### 6. 状态站与导航站的深色蒙版

引入独立的 `--bg-scrim`(浅色同 `--body-overlay`,深色 `rgba(0,0,0,0.45)`),只供 `body::before` 用——直接改 `--body-overlay` 会连带改暗卡片填充层。

实测背景相对亮度(最亮采样点):**0.28 → 0.17**(状态站与导航站均已对齐)。注释里原本写的估算值已按实测改正。

页头文字原本直接压在照片上(浅色深蓝落照片暗部 1.14:1,深色浅蓝落照片亮部 1.34:1)。改成与卡片同款的磨砂底衬,用博客已有的 `linear-gradient(var(--body-overlay),…), var(--glass-bg)` 配方,文字落在受控底色上而非赌照片那一像素是亮是暗。

### 7. 博客首页 h1 + 归档页 h1

首页简介卡的站名补成真正的 `<h1>`(外层 h1 抹掉默认样式,视觉零变化);hero 标题 `h3` → `h2` 消除层级跳跃。

归档页此前整页一个标题元素都没有,补一个 `.sr-only` 的 `<h1>归档</h1>`。`.sr-only` 自己定义而没有借用 Font Awesome 里的同名类——FA 是异步加载的,它一掉这个类就会失效、标题直接显形。

### 8. 顶栏高度突变

见 P0-1,已一并解决。

## 两点需要你确认的遗留

1. **导航站的深色背景挂在 `@media (prefers-color-scheme: dark)` 上,而主题脚本写的是 `html.dark`** ——两者不同源。若将来给导航站加主题切换按钮,或用户手动设过 localStorage,会出现「卡片是深色、背景仍是浅色」。这次只把蒙版色值接到了 `--bg-scrim`,没动这个结构(改它需要一次性替换 6 条规则,且多行编辑在该文件上反复失配)。要改我再单独做一次。
2. **归档页只有屏读可见的标题** ——其余页面(文章/相册/说说/友链)都是可见标题,归档页没有,视觉上不统一。是否要加一个可见的「归档」标题,是设计取舍,我没有替你决定。
