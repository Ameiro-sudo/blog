## 结果概览

对比度不达标项（WCAG AA，4.5:1 正文 / 3:1 大字与图标）：

| 站点 | 浅色 | 深色 |
| --- | --- | --- |
| 博客 | 544 / 1985 (27.4%) → **17 / 1928 (0.9%)** | 29 / 1964 (1.5%) → **14 / 1928 (0.7%)** |
| MC 状态站 | 41 / 195 (21.0%) → **5 / 195 (2.6%)** | 29 / 195 (14.9%) → **2 / 195 (1.0%)** |
| 导航站 | 3 / 51 (5.9%) → **0 / 51** | 3 / 51 (5.9%) → **0 / 51** |

20 个「页面 × 主题」组合中 13 个归零。结构性指标同时清零：页面级横向溢出、
移动端导航可达性、首页 h1 缺失、标题层级跳跃、键盘焦点样式缺失。

- **博客** → `Ameiro-sudo/blog`
- **个人主页 / 状态站 / 导航站** → `Ameiro-sudo/Ameiro-sudo.github.io`、
  `Ameiro-sudo/inecraft-Server-Status-test`

三个站点的 `assets/css/tokens.css` 保持**字节级一致**
（MD5 `C0D7EBA8EFC71EB66659A9FD0DF0A737`，9488 bytes）——审查期间发现三站的
设计 token 长期各改各的，本次把状态色与蒙版 token 收口后统一同步。
用 md5 核对即可验证是否被单独改过。

## 复跑验证

审查脚本与采样数据在 `C:\Users\Administrator\.visual-audit\`，与审查阶段同一套。
其中 `focus.cjs` 是修正后的键盘焦点检测——此前版本把元素聚焦后的样式与聚焦中的
样式作比较，等于自己跟自己比，结论不可用。
