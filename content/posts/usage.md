## 文章列表

首页按时间倒序列出所有文章，置顶文章（带 `[置顶]` 标记）排在最前。

每页显示 5 篇，底部分页栏支持：
- 上一页 / 下一页
- 直接点击数字跳转
- 首尾页快速跳转
- 省略号表示中间折叠的页码

每张文章卡片包含：标题、日期、标签、置顶标记、摘要、阅读时间。

---

## 搜索

顶部搜索框输入即搜，250ms 防抖延迟，不打扰打字节奏。

搜索范围：标题、标签、日期、正文摘要。匹配的关键词在标题和摘要中以黄色高亮显示。

快捷键：`Ctrl+K`（Windows/Linux）或 `Cmd+K`（Mac）快速聚焦搜索框。

---

## 标签筛选

搜索栏下方展示所有标签，按文章使用频率自动调整字号：
- size-1（小）：低频标签
- size-2（中）：中频标签
- size-3（大）：高频标签，加粗

**用法：**

| 操作 | 效果 |
|------|------|
| 点击标签 | 筛选该分类的文章 |
| 再次点击同一标签 | 清除筛选 |
| 点击 "x 清除筛选" | 清除筛选 |
| 叠加搜索 | 搜索框 + 标签同时筛选 |
| 点击文章卡片上的标签 | 快速筛选该分类 |

## 归档

导航栏点击「归档」进入归档视图，包含两部分：

### 年度热力图

GitHub 风格的贡献图，直观显示一年中每天的写文频率：
- 色块越深，当天发文越多（共 4 级）
- 悬停（或点击）查看当天具体篇数
- 点击方块弹出当日文章列表，点击文章可跳转阅读
- 顶部按钮切换年份（仅显示有文章的年份）

### 时间轴

按年月分组展示所有文章和相册：
- 年份 → 月份 → 文章/相册列表
- 相册条目带 `[相册]` 标记
- 点击文章或相册直接跳转

## 画廊

导航栏点击「画廊」进入照片墙，瀑布流布局展示所有相册。

### 相册列表

每个相册以堆叠卡片样式展示（三层叠加，带旋转和灰度效果，鼠标悬停有动效）。显示相册标题、日期、简介。

### 相册详情

点击相册进入详情页：
- 顶部标题 + 日期 + 照片数（「N 个瞬间」）
- 正文使用 CSS columns 瀑布流布局，图片自然交错排列
- 分批加载（IntersectionObserver 监测，每次加载 12 张，向下滚动自动触发下一批）
- 预加载机制：当前批加载完成后自动预加载下一批

### 图片灯箱

点击照片打开灯箱：
- 全屏黑色毛玻璃遮罩
- 图片居中，最大 90vw × 85vh
- **缩放：** 滚轮逐级缩放、双击切换 1x/2.5x、触摸设备双指缩放
- **平移：** 缩放后鼠标拖拽或单指拖拽平移（1x~5x 范围）
- **关闭：** 点击遮罩、点击 X 按钮、按 Esc
- **EXIF 展示：** 底部左侧显示照片参数

### EXIF 信息

相机直出的照片会在灯箱底部自动显示：
- 相机品牌 + 型号（如 Xiaomi Redmi K30 5G）
- 光圈（如 f/1.89）
- 快门速度（如 1/930s）
- ISO（如 ISO 50）
- 焦距（如 5mm）
- 图像尺寸（如 4624x2600）

截图、网页下载图等不含 EXIF 的照片不显示。

## 文章阅读

### 文章页面

点击文章卡片进入阅读模式，包含：
- 大标题 + 元信息（日期、时间、阅读时间、字数、标签）
- Markdown 渲染正文
- 代码块：Atom One Dark 主题 + 行内复制按钮 + 语言标签
- 表格：响应式包裹，水平可滚动
- 图片：圆角阴影，点击打开灯箱
- 底部相关文章推荐（按标签重合度排序）

### 文章目录

右下角 ≡ 按钮打开目录面板：
- 自动提取 h2/h3 标题
- 点击目录项平滑滚动到对应位置
- 滚动时自动高亮当前可见章节（IntersectionObserver）

### 阅读进度条

页面顶部固定一条 3px 高的渐变色进度条，从冰蓝渐变到暖金色。随文章滚动从左到右填充，随时掌握阅读进度。

### 随机文章

地址栏直接输入 `#/random` 或点击随机链接，随机跳转一篇文章。

### 返回列表

文章底部「← 返回文章列表」链接，或浏览器后退按钮。

## 快捷键

| 按键 | 功能 |
|------|------|
| `Ctrl+K` / `Cmd+K` | 聚焦搜索框 |
| `Esc` | 关闭灯箱 |

**灯箱内：**

| 操作 | 功能 |
|------|------|
| 滚轮向上 | 放大 |
| 滚轮向下 | 缩小 |
| 双击 | 切换 1x / 2.5x |
| 鼠标拖拽 | 平移已放大的图片 |
| 触摸双指捏合 | 缩放 |
| 触摸单指拖拽 | 平移 |
| 快速双击（触摸） | 切换 1x / 2.5x |

## 关于页面

导航栏「关于」显示站点信息和联系方式。内容从 `content/pages/about.md` 加载，支持 Markdown。

## 技术细节

- 纯前端 SPA，零后端，无数据库
- 所有文章和页面通过 fetch 动态加载
- 构建时生成索引确保快速浏览
- 版本哈希保证资源更新后浏览器立即获取最新版
- Service Worker 缓存 CDN 图片加速重复访问
- 图片 CDN 缓存通过构建时间戳刷新

项目架构与维护见[《SnowBlock 博客项目总览》](#/post-3)。
