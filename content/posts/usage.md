# 博客功能一览
date: 2026-06-06
tags: 指南, 功能
time: 11:00
readTime: 3 分钟
---

## 浏览

首页按时间倒序列出文章，置顶文章在最前。每页 5 篇，底部翻页。

## 搜索

顶部搜索框实时筛选，匹配标题、标签、日期和正文。`Ctrl+K` / `Cmd+K` 快速聚焦。

## 标签

搜索栏下方标签云，字号反映使用频率。点击筛选，再次点击清除。

## 归档

「归档」按年月展示文章和相册，顶部热力图显示发文频率。

## 画廊

「画廊」瀑布流展示相册，点开分批加载照片。相机直出的照片在灯箱底部显示 EXIF 参数。

## 文章阅读

文章中打开目录面板（右下角 ≡），滚动自动高亮。顶部有阅读进度条。

## 随机

地址栏输入 `#/random` 跳到随机文章。

## 订阅

RSS 阅读器添加 `https://blog.snowblock.top/feed.xml`。

## 快捷键

| 按键 | 功能 |
|------|------|
| `Ctrl+K` / `Cmd+K` | 搜索 |
| `Esc` | 关闭灯箱 |
| 滚轮 / 双击 | 缩放灯箱图片 |
| 拖拽 | 平移已放大的图片 |

项目架构与维护见[《SnowBlock 博客项目总览》](#/post-3)。
